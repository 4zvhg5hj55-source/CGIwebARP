NOVEDADES v2.1
  - Notas informativas e informes con NIVELES: 1 = todos los miembros (incl. alumnos) · 2 = Analista o superior · 3 = Coordinador o superior.
    Las mismas pestañas, con filtro por nivel arriba. Un Coordinador o superior puede cambiar el nivel y dar acceso a personas concretas
    (botón «Gestionar acceso» en las notas y «Acceso» en los informes). Si un informe se asocia a una investigación, lo ve quien pueda ver la investigación.
  - Perfiles de acceso: botón «Descargar datos» (CSV para Excel, sin contraseñas).
  - Investigaciones rediseñadas: panel con estado, fase (Apertura → Cierre), equipo, contadores, datos clave con iconos,
    personas con foto, cronología de actividad, filtros y accesos rápidos.
  - Nuevos títulos: DAO y Co-Desarrollador. Jerarquía: Desarrollador > FL > Co-Desarrollador > DAO.
    Desarrollador, Co-Desarrollador y DAO pueden llevar un RANGO CGI (opcional): salen en Placas y pueden llevar/estar en investigaciones.
  - Modo desarrollador (Desarrollador y Co-Desarrollador): desactivado = solo el acceso de su rango; activado = acceso total.
    Se desactiva solo en cada inicio de sesión y queda registrado en los logs.
  - El DAO tiene siempre acceso de supervisión (como FL) pero NO entra en el Panel Desarrollador.
  - Solo un Desarrollador puede gestionar cuentas Desarrollador (un Co-Desarrollador no puede tocarlas ni ver su contraseña).

DESPLIEGUE NUEVO (una sola vez, necesitas Node.js 18+ y una cuenta de Cloudflare)
  1. Descomprime el zip y abre una terminal dentro de la carpeta.
  2. npm install
  3. npx wrangler login          (se abre el navegador; autoriza)
  4. npx wrangler deploy
  5. Te dará una URL tipo  https://cgi-andaluciarp.TU-CUENTA.workers.dev

ACTUALIZAR UNA WEB YA DESPLEGADA SIN PERDER NINGÚN DATO
  Los datos viven en la base de datos del Durable Object, que NO se toca al redesplegar mientras no cambies estas tres cosas de wrangler.jsonc:
     name = "cgi-andaluciarp"  ·  class_name = "CGI"  ·  migrations (tag "v1")
  1. COPIA DE SEGURIDAD: entra como dev > «Modo desarrollador» > Panel Desarrollador > ⬇️ Copia de seguridad. Guarda el .json.
  2. En tu carpeta del proyecto sustituye src/, public/, package.json y LEEME.txt por los de este zip.
     NO sustituyas ni edites wrangler.jsonc (en este zip es idéntico al anterior).
  3. npx wrangler deploy
  4. Entra y comprueba: las notas y los informes siguen ahí. La primera petición migra los datos antiguos automáticamente:
       · notas «Reservado» -> Nivel 1 · «Confidencial» -> Nivel 3 · «Secreto» -> Nivel 3 pero siguen limitadas a Secretario General o superior
       · informes existentes -> Nivel 3 (así se comportaban hasta ahora: autor, compartidos, equipo de la investigación y Coordinador+)
       · las personas con acceso concedido («compartido») se conservan
  NO pongas la variable CGI_KEY: cambiaría la clave de cifrado y las contraseñas guardadas dejarían de poder mostrarse.
  Si algo fallara, Cloudflare permite volver a la versión anterior (Workers > cgi-andaluciarp > Deployments > Rollback): los datos nuevos son
  compatibles hacia atrás y las notas siguen igual de protegidas.

DATOS
  - Se guardan en una base de datos SQLite persistente (Durable Object). No se borran al redesplegar.
  - Haz copias de seguridad con el botón de copia del Panel Desarrollador (/api/backup).

SI PIERDES EL ACCESO A "dev"
  - En wrangler.jsonc añade   "vars": { "DEV_RESET": "1" }   ->  npx wrangler deploy  -> entra con dev -> quita la línea y vuelve a desplegar.
